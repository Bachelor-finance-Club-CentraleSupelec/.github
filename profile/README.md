# Bachelors Finance Club · CentraleSupélec

Student finance club of the Bachelor programme at CentraleSupélec (Paris-Saclay), part of the Bureau des Bachelors.
We learn markets by doing: stock pitches, macro updates, risk analysis, quantitative backtests and a real student-run portfolio.
